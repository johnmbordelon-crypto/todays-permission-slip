TODAY'S PERMISSION SLIP — PWA PACKAGE

FILES
- index.html: the app
- manifest.webmanifest: install metadata
- service-worker.js: offline support
- icons/: app icons

IMPORTANT
A PWA must be served from HTTPS (or localhost). It will not install properly if
you simply open index.html directly from a phone's Files app.

EASIEST HOSTING OPTIONS
1. Netlify Drop:
   - Unzip this package.
   - Drag the whole folder onto Netlify Drop.
   - Open the resulting HTTPS address on the phone.

2. GitHub Pages:
   - Create a repository.
   - Upload all files from this folder.
   - Enable Pages from the repository settings.

INSTALL ON IPHONE/IPAD
- Open the hosted HTTPS address in Safari.
- Tap Share.
- Tap Add to Home Screen.
- Tap Add.

INSTALL ON ANDROID
- Open the hosted HTTPS address in Chrome.
- Open the menu.
- Tap Install app or Add to Home screen.

The selection is deterministic by date, so both people opening the app on the
same date will see the same pair of results.
